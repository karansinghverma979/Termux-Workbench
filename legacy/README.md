# 📱 Project Legacy Archives (2020–2025)

This directory preserves the historical configuration files used during the 2020–2025 Mobile Era:
- `termux.properties.legacy`: The original 2-row extra keys layout with early keybindings and macros.
- `zshrc.legacy`: The original ZSH shell config featuring the "Queen" / "Sarika" boot sequence, `lolcat` gradients, and early Python note utilities.

These files are preserved for historical provenance. For the modern, production-grade workstation environment, see the `config/` directory.
